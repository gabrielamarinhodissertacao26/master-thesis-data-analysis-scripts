# Magnetic microrheology for local stiffness measurement in TFM

Scripts used in the MSc dissertation *A novel measurement framework for 3D TFM in Heterogeneous media using superparamagnetic nanobeads* (Gabriela Marinho, University of Minho, 2026), developed in collaboration with KU Leuven.

The scripts analyze the displacement fields obtained with TFMLAB, the TrackMate tracks of the calibration experiments and the magnetic field simulated in FEMM.

## Structure

| Folder | Script | Description |
|---|---|---|
| `1_magnetic_source_selection` | `displacement_direction.m` | Percentage of displacement vectors per dominant displacement direction (exploratory trials). |
| | `plot_femm_B.py` | Analysis of the magnetic flux density simulated in FEMM (\|B\| and its gradient) for both magnet configurations. |
| | `plot_calibration_curve.py` | Plot of the calibration curve (magnetic force vs distance to the magnetic block). |
| | `trackmate_track_selection.py` | Selection of the TrackMate tracks and calculation of the terminal velocity of the beads for each distance (calibration). |
| `2_validation` | `heatmap_filter_step.m` | Heatmap of the displacement vectors per magnitude range and dominant direction, used to define the filtering step (0.3–8 µm). |
| | `medians_per_position.m` | Median of the filtered displacements per sample and position, and mean ± SD per position. |
| | `plot_validation_positions.m` | Bar plot of the displacements per position for both hydrogels. |
| | `repeatability_7trials.m` | Repeatability analysis (seven trials on the same sample). |
| | `percent_kept_filter.m` | Percentage of displacement vectors kept after the filtering step. |
| `3_force_displacement_estimation` | `plot_force_displacement.py` | Estimation of the magnetic force and of the bead displacements from the \|H\| simulated in FEMM (configuration 1). |

## Input data

- MATLAB scripts: displacement field files generated by TFMLAB (`D_2_displacements/beads/tp_01.mat`). The paths at the beginning of each script must be changed to the location of the data.
- `trackmate_track_selection.py`: TrackMate spots export (.csv) of each distance.
- `plot_femm_B.py` and `plot_force_displacement.py`: FEMM line exports (Plot X-Y → "Write data to text file"), placed in the same folder as the script.

The raw data are not included in this repository.

## Requirements

- MATLAB (R2020b or later, for `exportgraphics`)
- Python 3 with the packages listed in `requirements.txt`:

```
pip install -r requirements.txt
```
